# Contribuer
Utiliser la branche portfolio-cyber comme base. Décrire la motivation, les fichiers concernés, le comportement observable, le test et les limites dans la proposition. Employer uniquement des exemples fictifs. Toute modification du seuil doit fournir les effets sur atlas, boreal et cedre.

Exécuter les commandes du README avant de proposer un changement. Réviser manuellement les nouveaux paquets, leur licence, leur provenance et leurs dépendances. Avec un paquet externe, compléter le manifeste avec la fermeture transitive verrouillée et adapter le contrôle pip-audit. Examiner les mises à jour des actions par SHA. Les versions directes des outils de CI sont fixées ; leurs dépendances transitives et l’image du runner peuvent évoluer.
